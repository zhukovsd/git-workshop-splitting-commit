# Воркшоп по git - разбиение коммита

Контекст - в разных командах и проектах приняты разные правила касательно размера и атомарности коммитов. В командах, где ревью изменений требует чистой истории коммитов, часто возникает необходимость "чистить" историю своей ветки перед созданием Pull Request.

В рамках "чистки", может возникнуть необходимость разбивать коммит на несколько. Данный кейс фокусируется именно на этом.

Суть задачи:
- Коммит `96f81502` "feat(test): add unit tests" добавляет сразу 6 тестовых классов
- Необходимо разбить его на 6 отдельных коммитов, по одному классу в каждом

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Решите локально
- Сравните локальную и удалённую ветку master, разницы в файлах быть не должно, только в истории коммитов
